常见函数及其功能

range()函数

range() 函数可以接受一到三个整数参数，分别代表起始值、结束值以及步长。下面具体介绍这三个参数的作用：

  1. 单参数形式：range(stop)

  • 这种形式只提供结束值 stop，而起始值默认为 0，步长默认为 1。

  • 例子：for i in range(5): 会产生序列 0, 1, 2, 3, 4。

  1. 双参数形式：range(start, stop)

  • 这种形式提供了起始值 start 和结束值 stop，步长默认为 1。

  • 例子：for i in range(1, 5): 会产生序列 1, 2, 3, 4。

  1. 三参数形式：range(start, stop, step)

需要注意的是，range() 函数生成的序列不包含结束值 stop。也就是说，如果指定了 range(stop)，那么生成的最后一个数字将是 stop - 1。

  • 这种形式提供了起始值 start、结束值 stop 和步长 step。

  • 例子：for i in range(0, 10, 2): 会产生序列 0, 2, 4, 6, 8。

yield函数

yield 是 Python 中的一个关键字，它用于定义生成器（generator）函数。生成器是一种特殊的迭代器，可以暂停执行并保存当前的状态，以便稍后恢复执行。相比于普通的函数，生成器在处理大量数据时更加节省内存，因为它们只在需要时才生成下一个值，而不是一次性生成所有值。

当一个函数中包含 yield 语句时，这个函数就变成了一个生成器。每次调用生成器时，它会从上次停止的地方继续执行，直到遇到下一个 yield 语句或者函数结束。

yield 的特点

  1. 惰性求值：生成器只有在被迭代时才会产生下一个值，而不是一次性计算所有值。

  2. 状态保存：生成器在每次执行到 yield 时都会保存当前的状态，下次调用时从中断处继续执行。

  3. 内存效率：生成器在处理大量数据时占用的内存较少，因为它只在需要时才生成数据。

类的定义

类有一个特殊的方法叫做构造函数，主要作用是定义实例对象的属性，命名为_init_()，括号里面可以放任意数量的参数，但第一个参数永远被占用，得的用于表示对象自身，叫self，它能将属性的值绑定在实例对象上。

继承

子类会继承父类的属性和方法

子类继承父类可以直接类名后面的括号中写入父类的名字

如果子类中没有构造函数，则会直接继承父类中的构造函数

在方法调用中，如果子类中有该方法，则会调用自己的方法，如果没有则会调用父类中的方法，背后的逻辑：优先看所属的类有没有该方法，没有的话往上找父类同名方法用

根据上述所说，如果子类中有构造函数则就会优先调用子类的构造函数，而不是父类的构造函数，这样就继承不了父类中的属性。

在子类的构造函数里面写super.****_init_()，这就会调用父类里的构造函数

类的私有属性和方法

在属性名前两个下划线开头，声明这个属性为私有。不能再类的外部使用或直接访问。

在方法名前添两个下划线，这方法被会被声明成一个私有方法，不能被类的外部直接使用或访问。

异常

捕捉异常使用try:，使用**except [异常类型名]:**对异常进行处理

如果不知道异常的名称则可以直接用**except:**这样不管是什么类型的异常都会执行

如果有多个异常类型的，在捕捉到第一个异常进行语句执行操作之后，后面的except就不会再执行。

如果程序没有异常则可以在里面添加else语句，然后再else里面写入没报错时需要执行的语句。

在使用**finally:**语句，不管程序有没有异常，异常没有被捕捉到都会执行finally里面的语句。

测试函数

assert语句后面接任意的布尔表达式，如果assert语句后面的表达式为True则无事发生，继续运行后面的代码，如果后面的表达式为False则会报错误

如果直接使用assert语句只想到错误语句的时候程序就炸了，后面如果有更多的assert语句（也不会被执行），我们并不知道还有其他问题，所以我们一般使用做测试的库，结合assert使用

建立测试文件文件名很重要，pytest库会自动寻找以test_文件名开头和以**_**test文件名结尾的.py文件

符合标准的文件名例子：test_my_calculator.py 或者my_calculator_test.py

在测试文件里面想要测试的语句必须放在函数里面，注意函数名要以test_开头，pytest才能自动找到测试用例

在终端输入pytset可以进行测试，也可以在pytest后面加空格文件名，对单个文件进行测试

不同的测试用例之间是独立的，如果要测试一个类，那就要不断的创建新对象，为了减少不必要的重复代码，使用fixture修饰器。

具体的可以新创建一个函数，在函数里面将类创建好，并返回这个类。然后将这个函数名作为参数添加到其他几个需要使用类的函数中，直接把传入的参数作为测试对象，同时在这个函数前加上@pytest.fixture，这样在运行各个测试函数之前，这个函数都会运行一次。并把返回的内容作为参数传给各个测试函数。

用fixture修饰的方法在每一个用例测试前都会运行一遍
